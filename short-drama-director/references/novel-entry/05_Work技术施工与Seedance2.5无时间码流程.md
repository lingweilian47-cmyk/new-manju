# Work 技术施工与 Seedance 2.5 七段式无时间码流程

> ⭐ **小说入口 Work 总控（★权威）**：本文件承接冻结 S3，把基础镜头施工为真实空间中的可执行镜头，再装配为接近 30 秒的 Seedance 2.5 生成组，最终输出七段式无时间码 Prompt。
>
> **核心公式：**先摆人，再摆摄影机；先完成镜头，再装生成组；所有判断完成后，最后才写 Prompt。

---

## 〇、模型与交付合同

```text
模型：Seedance 2.5
默认参考模式：全能参考模式
提示词：七段式
生成组：按自然声画尽量接近 30 秒，但不以填满为合格证
内部：必须估时、校准容量与模型负载
最终交付：禁止时间码、数字秒数和时长控制指令
```

`【时间轴分镜】`中的“时间轴”只表示镜头、动作、声音与状态按真实发生顺序排列，不写 `00:00-00:05`、`3秒`、`停顿两拍`。

## 二、W1｜空间与人物可见性编译

### 1. 先位后机

每镜先确定：

```text
画内人物／画外人物
人物位置与前中后景
人物之间的功能距离
依托物与分隔物
身体朝向、脸部朝向与视线
道具持有人、左右手与接触状态
本镜允许位移：起点 → 路径 → 终点
开镜状态与结束状态
```

未完成以上项目，不得先选景别和运镜。

### 2. 功能距离

| 距离 | 适用关系 | Prompt 可执行写法 |
|---|---|---|
| 接触位 | 递物、抓握、搀扶、近身攻击、耳语 | 相距一臂以内；伸手可触；手已接触具体部位 |
| 交谈位 | 柜台交易、双人对话、当面对峙 | 隔着某物相距约一至两步；无需移动即可交谈 |
| 观察位 | 护卫、旁观者、等待介入者 | 位于主体侧后方约三至五步；不进入主要行动区 |
| 分隔位 | 戒备、权力差、隐藏观察、空间阻碍 | 由柜台、门框、货架、桌面、走廊或纵深明确隔开 |

每镜记录：开镜距离、距离是否变化、结束距离。距离变化必须有动作原因。

### 3. 景别可见性门

当前景别无法容纳远处人物的有效表演时，只能三选一：

1. 放宽景别，使人物按真实距离同框；
2. 拆出 S3 已允许的独立观看任务；
3. 保持人物画外，用声音或主体反应承载。

不得把远处配角偷偷移动到主体身旁，也不得复制第二个角色。

## 三、W2｜技术摄影与表演施工

### 1. 选择顺序

```text
镜头功能
→ 人物距离与动作路径
→ 必须同时看见的信息
→ 最紧可用景别
→ 观察方向与角度
→ 静态开镜构图
→ 是否需要摄影机运动
→ 动作、表演、特效与声音过程
→ 结束落点
```

### 2. 景别选择

- 大全景／全景：空间、站位、路线、规模、覆盖范围与大型结果；
- 双人／多人中景：关系互动、同步接收、喜剧错位、暧昧试探、动作发起者与承受者同框；
- 中景：身体姿态、手部动作、走动、转身、递物与局部环境；
- 中近景：面部与手部同时重要、对白中的细小动作与掩饰；
- 近景：认知改变、情绪结果、反应改变前一动作意义；
- 特写：决定性证据、接触点、物件、伤势、法术落点。

选择能保住全部必要信息的最紧景别。特写不能同时要求完整全身与环境路线。

### 3. 构图写法

构图只写第一帧可见事实：

```text
第一视觉主体
第二主体／接收者
前景、中景、后景关系
画面左／右／中央
人物朝向与可见面
分隔物、遮挡与关键物件
留白与行动方向
```

竖屏多人优先使用前中后景、高低层次与纵深错位，不把多人横排成一堵墙。

### 4. 先静后动

固定是默认可用答案。只有观看关系必须改变时才运镜。

- 跟拍：人物路线本身有价值；
- 推近：同一连续过程中信息或情绪逐步聚焦；
- 拉远：揭示孤立、规模、后果或更大空间；
- 摇摄／俯仰：注意力在同一空间转向另一对象；
- 横移／侧移：通过视差揭露遮挡或改变关系；
- 环绕：绕行本身改变关系几何，且有真实通路。

每次运镜必须明确：何时开始、由什么触发、运动路径、停在哪里。不得用“增强电影感”“营造压迫感”代替可见变化。

### 5. 表演施工

- 继承 S1 情绪依据与 S2 场景体验，不重新配情绪；
- 将抽象情绪翻译为视线、呼吸、手部、身体重心、距离和语气；
- FACS 只在关键近景、口是心非或高风险表演中按需调用，AU 编号不进最终 Prompt；
- 说话者不自动成为观看对象；
- 反应能在同框、后景或画外完成时，不机械拆近景。

## 四、W3｜内部容量与 30 秒装组

### 1. 内部估时账

每镜内部估算：

```text
对白自然发声时长
主动作自然时长
无法同期的前置／后置动作
必要情绪与结果读取
摄影机运动完成过程
能力／特效作用与残留建立
最低／常态／上限容量
```

同期内容只计一次：对白期间动作、听者同步接收、走动中说话、法术飞行时目标应对。

### 2. 生成组装配

- 按 S3 镜头顺序连续累计，不因凑时长打乱；
- 优先保留同一空间、同一声场、同一未完动作；
- 内容不足时，先接入下一连续镜头，不新增走路、对视、空镜、重复表情或无功能运镜；
- 内容超载时，在稳定结果、动作阶段完成、关系／距离改变、场景转换或情绪换挡处拆组；
- 长镜可以单独成组，但必须持续产生新动作、关系、信息、压力或空间变化；
- 接近 30 秒是装配目标，不是必须填满的硬指标。

### 3. 模型负载

同时变化的主体、多人换位、长对白、复杂接触、复杂特效、场景切换和摄影机运动越多，负载越高。过载时优先：

1. 简化摄影机运动；
2. 减少同一时刻变化的主体；
3. 把复杂接触放入独立观看任务；
4. 使用画外声承载不必可见的声音；
5. 调整生成组边界。

不得优先删除故事结果、人物接收和能力机制。

## 五、W4｜七段式无时间码 Prompt

固定顺序：

```text
【画幅风格】
【场景资产】
【核心人物】
【站位声明】
【时间轴分镜】
【接续状态】（属于时间轴分镜末尾强制尾行）
【音效】
【强制禁止项】
```

### Prompt 清洁铁律

1. 一个信息只有一个主要归属，禁止跨字段反复解释；
2. 只写采用答案，不写候选、分析、评分和导演理由；
3. 抽象情绪改写成可见动作或可听语气；
4. 复杂场景少用“他／她／对方”，使用标准人物名；
5. 动作按真实发生顺序书写，明确发起者、对象、接触与结果；
6. 每镜一个主要动作链，可附一个同步反应和一个明确结果；
7. 最终 Prompt 禁止时间码、数字秒数、镜长、总时长与“停顿几拍”；
8. 时间只通过镜头数量、动作量、对白量、同期关系与可见结束条件隐式控制；
9. `【强制禁止项】`只写本组高风险错误，不堆通用负面词仓库；
10. 接续状态写实际人物位置、持物、朝向、未完动作与特效残留，不写“保持连续”四个空字。

## 六、W5｜双层 QA 与返回

### 机械 QA

- 七段式段序齐全；
- Seedance 2.5 与画幅声明正确；
- 最终 Prompt 无时间码、数字秒数和时长指令；
- 镜头编号连续；
- 接续状态存在；
- 资产引用均有真实来源；
- 声音字符与台词归属正确；
- 禁止项未污染正文。

### 语义 QA

- 人物数量、距离、站位、朝向和可见性成立；
- 景别能真实容纳所写主体、动作和环境；
- 道具来源、左右手、交接与归属连续；
- 动作有接触、受力、反馈和结果；
- 能力有来源、路径／覆盖、作用、结果与残留；
- 运镜有触发、路径和停止位置；
- 生成组没有空动作、重复建立和无效停顿；
- S1/S2/S3 权威未被 Work 静默修改。

修改后必须执行：局部验证 → 联动冲突检查 → 全量审核。
