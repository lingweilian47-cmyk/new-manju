# Seedance 2.5 七段式无时间码合同｜Novel-2.5-NTC

> ⭐ **最终投喂合同（★权威）**：小说入口的正式 Prompt 只使用本合同。内部可以有秒数、容量区间和组长账本；交给视频模型与用户的最终 Prompt 不写任何时间码、数字秒数或时长控制语句。

---

## 一、固定段序

```text
【画幅风格】
【场景资产】
【核心人物】
【站位声明】
【时间轴分镜】
【接续状态】
【音效】
【强制禁止项】
```

`【接续状态】`属于 `【时间轴分镜】`的强制尾行，不计为独立第八段；“七段式”为唯一格式名称。

---

## 二、标准模板

```text
【画幅风格】
9:16 竖屏，Seedance 2.5，全能参考模式；[项目已批准画风、材质、光影和画面清洁要求]。

【场景资产】
@SCN-场景名：锁定[空间骨架、固定锚点、入口、主要功能区与当前状态]。

【核心人物】
- @CHR-人物A：锁定[身份、脸型、发型、体型、服装与本组状态]；
- @CHR-人物B：锁定[身份、脸型、发型、体型、服装与本组状态]。

【站位声明】
人物A（画面位置 · 依托物 · 身体朝向 · 当前姿态）；
人物B（画面位置 · 依托物 · 身体朝向 · 当前姿态）；
人物距离：[隔着什么／相距几步／是否伸手可触]；
轴线锁定：[主观察侧与左右关系]；
位移路径：[人物A 起点→路径→终点；人物B 原位／位移]；
画外人物：[姓名、方向、声音状态；无则写无]。

【时间轴分镜】
[镜头1] [景别] · [观察方向与角度] · [固定或具体运镜]。
[人物标准名]从[开镜动作]开始，[按真实顺序完成主要动作]；[接收者]同步[可见反应]；[物件／环境／能力]产生[明确结果]。声音：<环境声／物理音效>。台词：{人物A：“……”}／无。

[镜头2] [景别] · [观察方向与角度] · [固定或具体运镜]。
……

【接续状态】
人物A位于……，朝向……，持有……；人物B位于……；当前未完动作……；场景、光线、伤势、能力与特效残留……；下一组从……开始。

【音效】
[整组持续环境声、声音层级与对白清晰要求]；无背景音乐（用户另有批准时除外）。

【强制禁止项】
画面：[本组高风险人物、站位、道具、特效和文字错误]；
文字：禁止字幕、水印、乱码与无关可读文字；
声音：禁止新增台词、错误发言人和未批准音乐。
```

## 三、无时间码规则

最终 Prompt 禁止出现：

```text
00:00-00:05
3秒／约5秒／持续十秒
本组30秒／总时长
停顿两拍／保持三拍
镜头时长／时间码
```

允许使用可见的顺序与结束条件：

```text
同一时刻
话音未落
紧接着
看清以后
对方握稳后
笑意完全消失后进入下一镜
保持到人物完成掩饰动作
结果被看清后立即转向接收者
```

## 四、字段归属

| 信息 | 唯一主要位置 |
|---|---|
| 全组画风、画幅、模型与稳定光影 | 画幅风格 |
| 场景身份、骨架与固定锚点 | 场景资产 |
| 人物身份、外形与本组状态 | 核心人物 |
| 开镜位置、距离、朝向、轴线、位移 | 站位声明 |
| 镜内动作、构图结果、运镜、表演、特效与台词 | 时间轴分镜 |
| 组末真实状态 | 接续状态 |
| 整组持续声场 | 音效 |
| 当前组高风险错误 | 强制禁止项 |

同一站位、动作、情绪、光线和台词不得在多个字段写成互相竞争的版本。

---

## 五、Prompt 语言

- 写“人物在哪里、做什么、作用到谁、产生什么结果”；
- 不写“突出人物魅力、增强代入感、营造电影感、制造紧张氛围”；
- 写“眉间收紧、视线停住、手指握紧”，不写“十分愤怒”；
- 写“摄影机在人物抬头后沿视线上摇，停在空无一物的天空”，不写“摇镜制造悬念”；
- 写“蛇矛斗罗位于两人右后方三步，被货架边缘遮住小半身”，不写“蛇矛斗罗在旁边”；
- 一镜内容过载时拆技术实现或调整组边界，不用长串形容词硬压模型。
