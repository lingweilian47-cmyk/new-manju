# 小说漫剧已改编入口与 Work 交接｜Novel Adapted Entry

> ⭐ **小说入口总控（★权威）**：本文件定义本项目在已有冻结 `S1 / S2 / S3` 时，如何跳过原包的剧本生成，直接进入资产、空间、技术分镜、Seedance 2.5 投喂与质检。
>
> **核心原则：**不把小说直接当生产剧本，也不让 Work 重新编剧。小说经 Chat 三阶段处理后，形成已经通过故事、平台与基础分镜门控的生产输入包。

```text
入口 A｜原项目从零创作
```

发现 `S1 / S2 / S3` 冻结稿时，自动进入入口 B。不得仍从 `/写剧本`、五阶门控或台词改写重新生成另一版故事。

## 一、权威关系（最高优先级）

```text
S1：人物底盘、人物弧线位置、真实心态、动作依据、物件因果、能力／特效机制与残留状态权威。
S2：当前单集范围、事件顺序、确认对白、场景体验、情绪节奏、必要停留与节奏禁区权威。
S3：镜头数量、镜头功能、主要观看对象、同框／拆镜、声画承载、切镜理由与基础画面关系权威。
Work：正式资产引用、人物距离、Blocking、精确景别、机位、构图、运镜、表演施工、30 秒装组、Seedance 2.5 执行语言与 QA 权威。
小说原文：事实核对与争议回查来源，不是 Work 恢复删减或新增处理的授权。
```

Work 不得静默执行下列操作：

- 重新选择剧情、改变集界或事件顺序；
- 删除、改写或补造 S2 已确认对白；
- 重新判断 S3 镜头数量与镜头功能；
- 因制作方便缩掉人物接收、能力结果或情绪落点；
- 回小说捞取 S2 已删内容，拼进 Prompt 填时长；
- 把原包固定镜数、15 秒习惯或金句反应镜规则覆盖到 S3。

## 二、P1-N 导入验收

### 1. 必须输入

```text
S1 冻结版本号与完整交接件
S2 冻结版本号与完整交接件
S3 冻结版本号与完整交接件
当前项目 Canon
正式人物／场景／道具资产（若已有）
目标画幅
用户明确锁定项
```

### 2. 版本联动

- S1 更新：其后的 S2、S3 与 Work 产物全部失效；
- S2 更新：其后的 S3 与 Work 产物失效；
- S3 更新：已有 Work 技术分镜、生成组与 Prompt 失效；
- 只改资产版本：故事和镜头功能不失效，但所有资产绑定、空间可见性与 Prompt 必须重编译。

### 3. 五阶门控映射

| 原项目 P1 门控 | 小说入口满足来源 | Work 行为 |
|---|---|---|
| Premise | S2 平台与观看价值控制卡 | 验收，不重写 |
| Structure | S2 入口、结尾、故事单元顺序 | 验收，不重排 |
| Beat | S2 单元核心变化、关系运动、情绪曲线 | 验收，不另造节拍 |
| Entity | S1 人物、物件、能力与连续状态 | 验收并转入资产提取 |
| Page | S2 连续事件稿与确认对白 | 验收，不改词 |
| Shot Intent | S3 镜头数量、功能与观看对象 | 直接进入技术施工 |

验收通过后记录：

```text
P1-N = IMPORTED_AND_SATISFIED
来源 = S1-VX + S2-VX + S3-VX
禁止重新运行剧本生成与基础分镜生成
```

## 三、Novel Production Pack｜小说漫剧生产输入包

Work 开始施工前，先把三份冻结稿整理为一个只读输入包。它只抽取，不创造。

```text
# 项目标识
作品名／单集号／S1版本／S2版本／S3版本／原文定位／画幅

# 权威声明
故事与对白权威：S2
人物、情绪、能力机制权威：S1
镜头数量与功能权威：S3
技术施工权威：Work

# 人物与实体
人物运行卡／知情边界／当前关系／物件归属／能力事实／残留状态

# 故事单元
单元ID／场景体验卡／入口状态／确认事件／确认对白／核心变化／出口状态

# 基础镜头
镜头ID／镜头功能／节奏功能／主要观看对象／基础画面关系／建议景别层级／动作声音／特效阶段／开镜与结束状态／内部容量区间／切镜理由／Work自由空间

# 返回项
需返回S1／S2／S3的问题与原因
```

下游模块默认读取该输入包和正式资产，不要求每个模块分别重新理解三份上游文件。

## 四、Work 返回协议

```text

内容过多／过少、单集范围、对白容量或场景体验问题 → 返回 S2
镜头数量、观看对象、同框／拆镜或镜头功能不成立 → 返回 S3
距离、站位、机位、构图、运镜、表演施工、30秒装组、Prompt措辞 → Work 内解决
```

返回必须写：问题镜头／单元、技术冲突、为什么不能保住现方案、必须保住的上游目标、建议由责任阶段裁决的选项。
