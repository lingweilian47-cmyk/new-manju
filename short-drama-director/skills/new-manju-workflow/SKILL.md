# New Manju 漫剧工作流入口

本文件仅用于插件安装与发现。它**不新增阶段、不改变权力边界、不定义小说专用入口**。

执行任何任务前，必须读取并以插件根目录的 `../../SKILL.md` 为唯一总控，再按其中引用的 `references/` 执行。

## 输入处理

### 已完成的专业生产剧本

- 将剧本视为原版流程中已经完成的 P1 剧本产物；
- 除非用户明确要求改写，不再生成另一版剧本；
- 从 P2 人物、场景、道具与声音提取开始；
- 继续资产核验、空间调度、镜头任务提取、镜头选择、合并与拆分、完整分镜、提示词和 QA；
- 剧本是故事事实主文件，项目合同、世界观、连续状态、已有素材与用户硬约束是普通生产附件。

### 故事想法、梗概或未完成剧本

按根 `SKILL.md` 的原版 P0→P5 流程执行，不跳过五阶剧本门控。

### 已有剧本与正式素材

核验资产版本后，从原版流程中尚未完成的阶段继续。

## 禁止建立的旁路

不得要求、识别或生成 S1／S2／S3、小说影视化母稿、抖音事件稿、Chat 基础分镜、冻结导入包或 P1-N。小说改编过程发生在插件外部；进入插件时，只按最终提供的专业剧本与生产附件工作。

用户明确提供的项目合同和硬约束优先于模板中的可选默认值，但不得因此新增另一套流程。
